# Портфолио «Нить преемственности» — многостраничный сайт

Структура файлов:
- index.html — главная страница с карточками блоков
- blok1.html ... blok5.html — пять разделов портфолио
- style.css — общий файл стилей
- img/ — 7 фотографий

Как опубликовать на GitHub Pages:
1. Загрузите все файлы и папку img в корень репозитория.
2. Settings -> Pages -> Source: main, папка / (root).
3. Через минуту сайт откроется по адресу вида https://имя_аккаунта.github.io/имя_репозитория/

Навигация и ссылки между страницами уже настроены:
каждый блок — отдельная страница, с любой страницы есть переходы «на главную» и «наверх».
В футере замените «ваша почта · телефон» на реальные контакты.
