КАК ОПУБЛИКОВАТЬ САЙТ (GitHub Pages)
1. Создайте репозиторий portfolio (Public).
2. Загрузите ВСЕ файлы из архива в корень: index.html, blok1-blok5.html, style.css и папку img.
3. Settings -> Pages -> Source: Deploy from a branch, Branch: main, папка / (root) -> Save.
4. Через 1-3 минуты сайт будет доступен по адресу https://ВАШ-ЛОГИН.github.io/portfolio/
Ссылки на блоки: .../blok1.html .../blok5.html
